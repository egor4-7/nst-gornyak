# НСТ «Горняк»

Главная страница — статический адаптивный портал с лесным баннером, ссылкой на `father.html`, быстрыми подсказками и карточками разделов с модальными окнами. Тексты, тарифы, расписания, контакты и профиль в окнах демонстрационные и требуют замены на проверенные данные. Поиск пока показывает быстрые подсказки, а не ищет по сайту или документам; погодные данные также демонстрационные.

Для публикации на GitHub Pages достаточно разместить `index.html` и `father.html` в корне репозитория. Схема [`supabase/schema.sql`](./supabase/schema.sql) не подключена к текущей странице.
