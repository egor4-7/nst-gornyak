# НСТ «Горняк»

Главная страница — статический адаптивный портал с погодным баннером, поисковой строкой с подсказками и карточками разделов. Сейчас ссылки карточек и подсказок являются заглушками; поиск не выполняет запросы по сайту или документам, а погодные данные и быстрые действия отображают демонстрационный интерфейс.

Для публикации на GitHub Pages достаточно разместить `index.html` в корне репозитория. Схема [`supabase/schema.sql`](./supabase/schema.sql) не подключена к текущей странице.
