# НСТ «Горняк»

Статическая главная страница публикуется на GitHub Pages и показывает разделы расписания транспорта, тарифов, новостей, документов и контактов НСТ «Горняк». Новости и документы загружаются из Supabase или, без настроек Supabase, хранятся только в `localStorage` текущего браузера. Документы открываются по сохранённым ссылкам; сами файлы нужно разместить отдельно. Кнопка входа пока показывает уведомление: авторизация в этой версии не реализована.

## Настройка Supabase

1. Создайте проект в [Supabase](https://supabase.com/).
2. В SQL Editor выполните содержимое [`supabase/schema.sql`](./supabase/schema.sql).
3. Откройте Project Settings → API и скопируйте Project URL и публичный `anon` key (не `service_role`).
4. В `index.html` замените `ВАШ_SUPABASE_URL` и `ВАШ_SUPABASE_ANON_KEY` в настройках `SUPABASE_URL` и `SUPABASE_ANON_KEY`.
5. Опубликуйте изменения `index.html` на GitHub Pages.

При настроенном Supabase сайт читает новости из таблицы `news` (`title`, `body`, `published_at`) и документы из `documents` (`title`, `description`, `file_url`, `created_at`). Для документов указывается публичная ссылка `http://` или `https://`; сам файл нужно предварительно разместить в доступном хранилище. Политики в `supabase/schema.sql` разрешают запись только аутентифицированным администраторам. Поскольку вход в текущем интерфейсе ещё не реализован, добавление записей в облако будет отклонено политиками базы данных; локальный демо-режим доступен без подключения Supabase.

Чтобы вручную подготовить администратора для последующей реализации входа, можно назначить им зарегистрированный аккаунт в Supabase SQL Editor:

   ```sql
   insert into public.site_admins (user_id)
   select id from auth.users where email = 'ваш-email@example.com'
   on conflict (user_id) do nothing;
   ```

Выполняйте это только для доверенных администраторов. Новые регистрации по умолчанию не получают права редактирования.

Публичный `anon` key предназначен для клиентского сайта. Не помещайте в HTML ключ `service_role`: он обходит политики доступа и предоставляет полный доступ к базе.
